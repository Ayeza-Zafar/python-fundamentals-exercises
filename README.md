# Python Fundamentals Practice

Welcome to my Python practice repository. This space documents my step-by-step journey learning core programming concepts in Python 3.15 before building real-world data science and utility projects.

## What This Repository Covers
* **Basic Syntax & User Input:** Using `input()`, `print()`, variables, and data type conversion (`int`, `float`, `str`).
* **Conditional Logic:** Writing decision-making programs with `if`, `elif`, and `else` statements.
* **Mathematical & Logical Operators:** Working with arithmetic, remainder/modulo (`%`), and comparison operators.
* **Loops & Iteration:** Automating repetitive tasks using `for` and `while` loops.
* **Functions & Lists:** Organizing reusable blocks of code and storing collections of data.

## How to Run Any Script
1. Ensure **Python 3.15** (or any Python 3.x version) is installed on your computer.
2. Download or copy any `.py` file from this repository.
3. Open the file in **IDLE** (or VS Code / Terminal) and press **F5** (or run `python filename.py`).
